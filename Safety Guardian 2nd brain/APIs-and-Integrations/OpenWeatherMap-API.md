# 🌤️ OpenWeatherMap API

- **Weather Endpoint**: `https://api.openweathermap.org/data/2.5/weather`
- **Air Pollution Endpoint**: `https://api.openweathermap.org/data/2.5/air_pollution`
- **Data Extracted**: Temperature ($^\circ\text{C}$), weather description, wind speed, humidity, AQI, $\text{PM}_{2.5}$, $\text{PM}_{10}$.
