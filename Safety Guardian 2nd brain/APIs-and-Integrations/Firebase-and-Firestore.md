# 🔥 Firebase & Cloud Firestore Integration

- **SDK**: Firebase Web v12 (`firebase/app`, `firebase/auth`, `firebase/firestore`)
- **Collections**:
  - `users/{uid}`: User settings, display profile, preferences.
  - `users/{uid}/medical/profile`: Emergency medical records.
  - `users/{uid}/contacts/{contactId}`: Emergency contact telephone directory.
  - `reports/{reportId}`: Live crowd-sourced hazard feeds.
  - `sos_events/{sosId}`: Active emergency dispatch queue.
