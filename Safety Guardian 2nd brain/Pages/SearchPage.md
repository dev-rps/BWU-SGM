# 📱 SearchPage (`SearchPage.jsx`)

- **Route**: `/search`
- **Key Modules**:
  - Debounced places autocomplete powered by TomTom Places API with Nominatim fallback.
  - Web Speech API voice search (`webkitSpeechRecognition`) with Hindi/English language model.
  - Popular Indian city shortcuts (Mumbai, Delhi, Kolkata, Bengaluru, etc.).
